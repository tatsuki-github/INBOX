# 調査の深さレベル定義

> 調査テーマの複雑度とユーザーの要求に応じて、3 段階の深さレベルを提供する。

---

## レベル定義

### 概要（Quick Scan）

| 項目 | 基準 |
|:---|:---|
| **目的** | テーマの全体像を素早く把握するための概要調査 |
| **サブトピック数** | 3-4 個 |
| **ソース数/トピック** | 2-3 件 |
| **レポート文字数** | 2,000-4,000 字 |
| **所要時間目安** | 10-15 分 |
| **エグゼクティブサマリー** | 100-200 字 |
| **ソース一覧** | 簡易（URL + 信頼性スコアのみ） |
| **論争マップ** | 省略可（主要な対立があれば 1 件のみ記載） |
| **付録** | なし |

**適用場面**: 初期スクリーニング、テーマの存在確認、会議前のブリーフィング

---

### 標準（Standard Research）

| 項目 | 基準 |
|:---|:---|
| **目的** | 意思決定に使える程度の信頼性・網羅性を持つ調査 |
| **サブトピック数** | 5-6 個 |
| **ソース数/トピック** | 3-5 件 |
| **レポート文字数** | 5,000-10,000 字 |
| **所要時間目安** | 20-40 分 |
| **エグゼクティブサマリー** | 300-400 字 |
| **ソース一覧** | 標準（URL + 信頼性スコア + 種別 + 参照セクション） |
| **論争マップ** | 主要な対立 1-3 件 |
| **付録** | 任意（比較表があれば推奨） |

**適用場面**: 技術選定、市場調査、競合分析、企画書のエビデンス補強

---

### 徹底（Deep Dive）

| 項目 | 基準 |
|:---|:---|
| **目的** | 学術レベルに近い網羅性と信頼性を持つ包括的調査 |
| **サブトピック数** | 6-7 個 |
| **ソース数/トピック** | 5-8 件 |
| **レポート文字数** | 10,000-20,000 字 |
| **所要時間目安** | 40-90 分 |
| **エグゼクティブサマリー** | 400-500 字 |
| **ソース一覧** | 詳細（URL + 信頼性スコア + 種別 + 参照セクション + 発行日 + 著者） |
| **論争マップ** | 全論争点を網羅（3-5 件） |
| **付録** | 必須（詳細比較表、用語集、検索クエリログ） |

**適用場面**: 投資判断、学術レポート、規制対応、重要な戦略意思決定

---

## 深さレベルの自動推奨ロジック

ユーザーが深さレベルを指定しない場合、以下のヒューリスティクスで推奨する:

| 判定条件 | 推奨レベル |
|:---|:---|
| 単語レベルの質問（「〇〇とは」「〇〇の概要」） | 概要 |
| 比較・選定を含む（「vs」「どちらが」「選定して」） | 標準 |
| 「徹底的に」「包括的に」「Deep Research」を含む | 徹底 |
| 規制・法律・学術テーマ | 徹底 |
| 市場調査・競合分析 | 標準 |
| 「最新動向」「トレンド」 | 標準 |
| テーマが 3 つ以上のドメインを横断 | 徹底 |

---

## 深さレベル間の切り替え

調査中にレベルを変更すべきケース:

| 状況 | 変更方向 | 理由 |
|:---|:---|:---|
| 情報が豊富で標準レベルの基準を容易に超えた | 標準 → 徹底 | 追加投資の価値がある |
| 情報がほとんど存在しない | 標準 → 概要 | スコープを縮小し、得られた情報を最大活用 |
| ユーザーから「もっと深く」とフィードバック | 任意 → 徹底 | ユーザー要求を優先 |
| 反復 3 回でも網羅性 60% 未満 | 徹底 → 標準 | 達成可能な基準に調整し、限界を明示 |
