# ソース信頼性 5 段階評価基準

> 情報の信頼性を一貫した基準で評価するためのルーブリック。
> 調査レポートの全ソースにこのスコアを付与する。

---

## 5 段階スコア定義

| スコア | レベル | 定義 | 典型ソース |
|:---:|:---|:---|:---|
| ★★★★★ | **一次情報源** | オリジナルデータ・研究の発信元。査読・公的審査を経ている | 査読済み学術論文、政府統計（e-Stat 等）、法令原文、特許文書 |
| ★★★★☆ | **高信頼二次** | 一次情報を信頼性の高い方法で分析・統合したもの | 大手コンサル報告書（McKinsey、Gartner）、公式ドキュメント、WHO/OECD レポート、業界団体白書 |
| ★★★☆☆ | **標準二次** | 専門性のある媒体による編集済みコンテンツ | 専門メディア記事（日経 xTECH、TechCrunch）、カンファレンス発表資料、出版社の書籍 |
| ★★☆☆☆ | **低信頼** | 個人発信や商業的バイアスの可能性があるもの | 個人ブログ（技術系含む）、企業マーケティング資料、プレスリリース、Qiita/Zenn 記事 |
| ★☆☆☆☆ | **未検証** | 出典不明、匿名、検証手段がないもの | SNS 投稿（X/Twitter）、匿名掲示板、ソース不明の転載記事、Wiki 系サイト |

## ソース種別ごとの典型スコアと注意点

| ソース種別 | 典型スコア | 昇格条件 | 降格条件 |
|:---|:---:|:---|:---|
| **査読済み学術論文** | ★5 | — | 撤回論文、プレプリント（査読前）は ★3 に降格 |
| **政府統計・法令** | ★5 | — | 古い版（最新版が存在する場合）は ★4 に降格 |
| **大手コンサルレポート** | ★4 | 調査方法論が明示 → ★5 | スポンサー付きレポート → ★3 に降格 |
| **公式ドキュメント** | ★4 | — | マーケティング色が強い場合 → ★3 |
| **専門メディア** | ★3 | 一次取材・独自データあり → ★4 | 他メディアの引用のみ → ★2 |
| **カンファレンス発表** | ★3 | 査読トラック → ★4 | ライトニングトーク → ★2 |
| **技術ブログ（企業公式）** | ★3 | 実データ付きの技術解説 → ★4 | 製品宣伝が主目的 → ★2 |
| **個人ブログ** | ★2 | 著名エンジニアで実証データ付き → ★3 | 意見のみ・データなし → ★1 |
| **プレスリリース** | ★2 | 第三者機関の検証付き → ★3 | — |
| **SNS 投稿** | ★1 | 公式アカウントの一次発信 → ★2 | — |
| **Wikipedia** | ★2 | 引用元を直接参照 → 引用元のスコアを適用 | 引用元未確認のまま使用 → ★1 |

## 判定フローチャート

```
ソースを取得
  ├─ 発信者は誰か？
  │   ├─ 政府 / 学術機関 / 国際機関 → ★4-5
  │   ├─ 大手コンサル / 業界団体 → ★4
  │   ├─ 専門メディア → ★3
  │   ├─ 企業（公式ブログ / PR） → ★2-3
  │   ├─ 個人 → ★1-2
  │   └─ 匿名 / 不明 → ★1
  │
  ├─ 査読 or 編集プロセスを経ているか？
  │   ├─ はい（学術査読、編集部チェック） → +1（上限 ★5）
  │   └─ いいえ → ±0
  │
  ├─ 一次データ / オリジナル調査を含むか？
  │   ├─ はい → +1（上限 ★5）
  │   └─ いいえ（他ソースの要約・引用のみ） → -1（下限 ★1）
  │
  └─ スポンサー / 商業的バイアスの可能性は？
      ├─ はい（スポンサー明示、製品宣伝） → -1
      └─ いいえ → ±0
```

## レポートでの使い方

### 品質基準

| 深さレベル | ★3 以上の比率 | ★4 以上の比率 |
|:---|:---:|:---:|
| 概要 | 60% 以上 | — |
| 標準 | 70% 以上 | 30% 以上 |
| 徹底 | 80% 以上 | 50% 以上 |

### ソース一覧での表記

```markdown
| # | ソース名 | URL | 種別 | 信頼性 | 発行日 | 参照 |
|:---|:---|:---|:---|:---:|:---|:---|
| S-1 | WHO Report on Microplastics | https://... | 国際機関レポート | ★★★★★ | 2025-01 | §2, §3 |
| S-2 | TechCrunch 記事 | https://... | 専門メディア | ★★★☆☆ | 2025-08 | §4 |
```

### ★2 以下のソース使用ルール

- ★2 以下のソースを単独の証拠として使わない
- ★2 以下のソースは「参考情報」として注記付きで引用する
- ★1 のソースは原則使用しない（★3 以上で裏が取れた場合のみ補足として引用可）
