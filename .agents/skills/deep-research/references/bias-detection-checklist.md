# バイアス検出チェックリスト

> 調査レポートの客観性を担保するための 8 種バイアス検出チェック。
> Step 6（品質検証）で全項目を適用する。

---

## 8 種バイアスと検出方法

### 1. 確証バイアス（Confirmation Bias）

| | 内容 |
|:---|:---|
| **定義** | 自分の仮説や先入観を支持する情報を優先的に収集・評価する傾向 |
| **検出質問** | 最初の仮説に反するソースを意図的に探したか？仮説を支持するソースと反証するソースの比率は？ |
| **チェック方法** | ファクトシートで「仮説を支持」「仮説に反する」をタグ付けし、比率を確認 |
| **合格基準** | 反証ソースが全体の 20% 以上含まれている |
| **対処法** | 「[テーマ] criticism」「[テーマ] limitations」「[テーマ] failure」で意図的に反証を検索 |

---

### 2. 選択バイアス（Selection Bias）

| | 内容 |
|:---|:---|
| **定義** | 特定の言語・地域・メディアに偏ったソース選択 |
| **検出質問** | ソースの言語分布は？地域分布は？メディア種別の分布は？ |
| **チェック方法** | ソース一覧の言語・地域・種別を集計 |
| **合格基準** | 単一言語が 80% を超えない（テーマが許す場合）。ソース種別が 3 種以上 |
| **対処法** | 不足している言語・地域・種別のソースを追加検索 |

---

### 3. 生存者バイアス（Survivorship Bias）

| | 内容 |
|:---|:---|
| **定義** | 成功事例ばかりに注目し、失敗・撤退事例が見落とされる |
| **検出質問** | 成功事例と失敗事例の比率は？撤退・中止した事例を調べたか？ |
| **チェック方法** | レポート内の事例を「成功」「失敗」「中止」に分類して比率を確認 |
| **合格基準** | 失敗・撤退事例が 1 件以上含まれている（テーマに該当する場合） |
| **対処法** | 「[テーマ] failure」「[テーマ] discontinued」「[テーマ] lessons learned」で検索 |

---

### 4. 権威バイアス（Authority Bias）

| | 内容 |
|:---|:---|
| **定義** | 著名な機関・人物のレポートを無批判に信頼する傾向 |
| **検出質問** | McKinsey / Gartner 等のレポートを無条件に正とみなしていないか？調査方法論を確認したか？ |
| **チェック方法** | ★4-5 ソースの主張を、異なるソースで裏取りしているか確認 |
| **合格基準** | 主要な主張は 2 ソース以上で裏取りされている |
| **対処法** | 権威ソースの調査母集団・方法論・スポンサーを確認。独立系ソースでクロスチェック |

---

### 5. 新しさバイアス（Recency Bias）

| | 内容 |
|:---|:---|
| **定義** | 最新の情報を過度に重視し、過去の重要なデータ・知見を無視する |
| **検出質問** | 直近 1 年のソースだけに依存していないか？歴史的な文脈を含めているか？ |
| **チェック方法** | ソースの発行日分布を確認。全ソースが直近 12 ヶ月に集中していないか |
| **合格基準** | テーマの時間軸に適した発行日分布になっている |
| **対処法** | 歴史的な転換点・前例のソースを追加。「[テーマ] history」「[テーマ] evolution」で検索 |

---

### 6. アンカリングバイアス（Anchoring Bias）

| | 内容 |
|:---|:---|
| **定義** | 最初に見つけたデータ・数値に引きずられ、後続の情報を過小評価する |
| **検出質問** | レポートの核心的な数値は複数ソースで確認したか？最初に見つけた数値をそのまま使っていないか？ |
| **チェック方法** | 主要な定量データ（市場規模、成長率等）のソース数を確認 |
| **合格基準** | 主要数値は 2 ソース以上で確認、または範囲（N-M）で記載 |
| **対処法** | 同じ指標を異なるソースで検索。「[指標名] [別の調査会社]」で比較 |

---

### 7. フレーミング効果（Framing Effect）

| | 内容 |
|:---|:---|
| **定義** | 情報の提示方法（ポジティブ/ネガティブ）によって解釈が変わる |
| **検出質問** | 同じ事実をポジティブにもネガティブにも解釈できないか？一方のフレームだけで提示していないか？ |
| **チェック方法** | レポートの [ANALYSIS] セクションで、ポジティブ/ネガティブ両面から記述しているか確認 |
| **合格基準** | 主要な分析で両面（メリット/デメリット、機会/リスク）が提示されている |
| **対処法** | 「一方で…」「ただし…」のカウンターバランスを意識的に追加 |

---

### 8. 公開バイアス（Publication Bias）

| | 内容 |
|:---|:---|
| **定義** | ポジティブ（有意）な結果ばかりが公開され、ネガティブな結果が埋もれる |
| **検出質問** | 「効果なし」「有意差なし」の研究も含まれているか？ |
| **チェック方法** | 学術テーマの場合、ネガティブ結果の論文を意図的に探しているか確認 |
| **合格基準** | 該当する場合、ネガティブ結果の研究が 1 件以上含まれている |
| **対処法** | 「[テーマ] no significant effect」「[テーマ] negative results」で検索 |
