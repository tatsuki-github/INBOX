# 質問カタログ — ドメイン別・カテゴリ別

> req-elicit の Step 3〜6 で参照するドメイン固有の質問集。

## 汎用カタログ（全ドメイン共通）

### 機能要件

| # | 質問 | 確認軸 |
|:---|:---|:---|
| F-01 | このシステムを使う主な人物は誰ですか？（役職・ロール・部署） | WHO |
| F-02 | 管理者と一般ユーザーで操作できる機能は異なりますか？ | WHO / 権限 |
| F-03 | 登録・参照・更新・削除のうち、必要な操作はどれですか？ | WHAT |
| F-04 | 一覧表示と詳細表示はどちらも必要ですか？ | WHAT |
| F-05 | 検索・フィルタ・ソート機能は必要ですか？ | WHAT |
| F-06 | データのエクスポート（CSV/Excel/PDF）は必要ですか？ | WHAT |
| F-07 | ファイルのアップロード・インポート機能は必要ですか？ | WHAT |
| F-08 | 操作完了後に通知（メール/プッシュ）を送る必要がありますか？ | NOTIFICATION |
| F-09 | 承認フロー（申請 → 承認 → 却下）は必要ですか？ | FLOW |
| F-10 | 処理が失敗した場合、ロールバック・取り消し機能は必要ですか？ | EXCEPTION |
| F-11 | 操作履歴（誰が・何を・いつ変更したか）の記録は必要ですか？ | AUDIT |
| F-12 | 定期的な自動処理（バッチ・スケジュール実行）は必要ですか？ | WHEN |
