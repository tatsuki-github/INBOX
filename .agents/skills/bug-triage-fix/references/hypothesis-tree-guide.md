# Hypothesis Tree Guide — 仮説ツリー構築ガイド

> 症状から根本原因への経路を体系的に絞り込む。闇雲なコード探索を防ぎ、最短経路で原因特定する。

---

## 症状カテゴリ → 仮説ツリー マッピング

### カテゴリ A: 例外・クラッシュ系

**症状**: `TypeError`, `NullPointerException`, `AttributeError`, スタックオーバーフロー

```
クラッシュ症状
├─ [A-1] Null / Undefined 参照
│   ├─ オプショナルな依存オブジェクトが初期化前にアクセスされた
│   ├─ API レスポンスが期待した構造でない（フィールド欠落）
│   └─ 削除済みデータを参照している
├─ [A-2] 型不一致
│   ├─ 文字列を数値として演算した
│   ├─ 配列を期待する箇所にオブジェクトが渡された
│   └─ JSON パース失敗
└─ [A-3] 無限ループ / 再帰
    ├─ 終了条件が機能していない
    └─ イベントが互いを発火させるサイクル
```

**調査起点**: スタックトレースの最上位行のファイル・行番号

---

### カテゴリ B: 認証・認可系

**症状**: `401`, `403`, ログインできない、他人のデータが見える

```
認証・認可エラー
├─ [B-1] 認証失敗
│   ├─ トークンの期限切れ・失効
│   ├─ パスワードハッシュのアルゴリズム変更
│   └─ セッションストアの破損
├─ [B-2] 認可ロジックの誤り
│   ├─ ロール判定条件のバグ
│   ├─ リソース所有者チェックの欠落（IDOR）
│   └─ 新機能追加時の権限定義漏れ
└─ [B-3] 設定・環境の問題
    ├─ 本番/開発でシークレットキーが異なる
    └─ CORS 設定の誤り
```

**調査起点**: 認証ミドルウェア → ユーザーモデル → セッション/トークン管理

---

### カテゴリ C: データ不整合・保存失敗

**症状**: 保存されない（エラーなし）、データが消える、計算値がおかしい

```
データ問題
├─ [C-1] サイレント失敗
│   ├─ 空の catch ブロックで例外を握りつぶしている
│   ├─ 非同期処理の await 忘れで結果を待っていない
│   └─ バリデーションが False を返すが処理が続く
├─ [C-2] DB 制約違反
│   ├─ UNIQUE 制約に違反する重複データ
│   ├─ NOT NULL 制約に違反する空値
│   └─ FK 制約に違反する存在しない参照
└─ [C-3] データ変換・計算のバグ
    ├─ 型変換（parseInt の基数未指定等）
    ├─ 浮動小数点の精度問題
    └─ タイムゾーン変換ミス
```

**調査起点**: バリデーション → DB クエリ → トランザクション境界

---

### カテゴリ D: 外部依存系

**症状**: 特定のタイミングで失敗、本番のみ失敗、インテグレーション失敗

```
外部依存問題
├─ [D-1] API / サービスの障害
│   ├─ タイムアウト（レスポンスが遅い）
│   ├─ レート制限（429 Too Many Requests）
│   └─ API 仕様変更（フィールド名変更等）
├─ [D-2] インフラ設定
│   ├─ 本番/開発の環境変数差分
│   ├─ ネットワーク制限（VPC、ファイアウォール）
│   └─ リソース上限（メモリ、CPU、ストレージ）
└─ [D-3] 非同期・タイミング
    ├─ イベントの到着順序が期待と異なる
    └─ Webhook の重複配信
```

**調査起点**: 外部サービスのステータスページ → ネットワークログ → 環境変数差分

---

### カテゴリ E: 競合状態・間欠エラー

**症状**: 「時々」失敗、負荷時のみ失敗、本番のみ間欠的に発生

```
競合状態
├─ [E-1] 二重操作
│   ├─ ボタンを素早く2回クリック → 二重送信
│   └─ 複数タブで同時操作
├─ [E-2] ロック競合
│   ├─ 複数トランザクションが同一リソースをロック
│   └─ ロック取得順序が一定でなくデッドロック
└─ [E-3] キャッシュ不整合
    ├─ キャッシュとDBの間でデータが乖離
    └─ キャッシュ期限切れのタイミング問題
```

**調査起点**: DB のロックログ → リトライログ → 並行アクセスパターン

## 仮説の優先順位付けマトリクス

| 仮説 | 可能性の根拠 | 調査コスト | 総合優先度 |
|:---|:---|:---|:---|
| ログに直接の証拠あり | 高 | 低 | **最優先** |
| 直近のコード変更と相関 | 高 | 低 | **優先** |
| データ状態が条件に合致 | 中 | 中 | **通常** |
| 環境差分が原因の可能性 | 中 | 高 | **後回し** |
| 理論上ありえるが証拠なし | 低 | 高 | **最後** |

## よくある「見落とし」パターン

| 見落とし | 発見のコツ |
|:---|:---|
| デプロイとの因果関係 | `git log --since="3 days ago"` で最近の変更を確認 |
| 設定値の差分 | `git diff origin/main -- .env.example` |
| DB マイグレーションの漏れ | マイグレーション履歴とコードのモデルを比較 |
| キャッシュの古いデータ | Redis / CDN キャッシュをクリアして再現確認 |
| 外部 API の仕様変更 | 外部 API の changelog を確認 |
| インデックスの欠落 | EXPLAIN で実行計画を確認 |
