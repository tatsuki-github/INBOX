# Security Checklist（OWASP Top 10 対応スキャンチェックリスト）

> Step 6 の実行リファレンス。Review Gate 6 の通過基準として、全項目を確認済みであることが求められる。

---

## OWASP Top 10 チェックリスト（A01〜A10）

### A01: アクセス制御の不備

- [ ] 認証ミドルウェアが全エンドポイントに適用されているか
- [ ] ユーザーが他ユーザーのリソースにアクセスできない設計になっているか（IDOR 防止）
- [ ] 管理者専用エンドポイントにロールチェックがあるか
- [ ] フロントエンドのみで制御されているロジックがバックエンドにも適用されているか

### A02: 暗号化の失敗

- [ ] パスワードが bcrypt/Argon2 等の強いハッシュで保存されているか（MD5/SHA1 を使っていないか）
- [ ] 機密データが平文で DB / ログ / レスポンスに含まれていないか
- [ ] TLS が強制されているか（HTTP へのフォールバックがないか）
- [ ] ハードコードされた認証情報・API キーがないか

### A03: インジェクション

- [ ] ユーザー入力が SQL クエリに文字列結合で組み込まれていないか（Prepared Statement を使用しているか）
- [ ] `exec()` / `eval()` / `subprocess.run(shell=True)` にユーザー入力が渡されていないか
- [ ] `innerHTML =` / `dangerouslySetInnerHTML` にユーザー入力が渡されていないか
- [ ] ファイルパスの構築にユーザー入力が使われている場合、パストラバーサル対策があるか
- [ ] テンプレートエンジンにユーザー入力がそのまま渡されていないか（SSTI 防止）

### A04: 安全でない設計

- [ ] 認証エンドポイントにレート制限（ブルートフォース対策）があるか
- [ ] パスワードリセットトークンが推測困難で有効期限があるか
- [ ] クレジットカード番号・SSN などが必要以上に表示・保存されていないか

### A05: セキュリティ設定ミス

- [ ] デバッグモード（`DEBUG=True` 等）が本番に残っていないか
- [ ] デフォルト認証情報（admin/admin 等）が変更されているか
- [ ] 詳細なスタックトレースがレスポンスに含まれていないか
- [ ] CORS が過剰に許可されていないか（`Access-Control-Allow-Origin: *`）

### A06: 脆弱なコンポーネント

- [ ] `npm audit` / `pip-audit` / `govulncheck` 等で既知脆弱性を確認したか
- [ ] メンテナンス終了パッケージを使用していないか

### A07: 認証の失敗

- [ ] JWT の署名が検証されているか（`alg: none` を受け入れていないか）
- [ ] セッション ID がログイン後に再生成されているか（セッション固定攻撃防止）
- [ ] トークンが `localStorage` ではなく `httpOnly Cookie` に保存されているか

### A08: ソフトウェアとデータの整合性

- [ ] 外部スクリプト（CDN）に SRI（Subresource Integrity）ハッシュがあるか
- [ ] ユーザー入力のデシリアライズが安全に行われているか

### A09: セキュリティログと監視の失敗

- [ ] 認証失敗・権限エラーがログに記録されているか（攻撃検知のため）
- [ ] ログに PII・パスワード・トークンが出力されていないか

### A10: SSRF（サーバーサイドリクエストフォージェリ）

- [ ] ユーザー入力 URL へのサーバーサイドからのリクエストが発生する箇所がないか
- [ ] ある場合、URL のホワイトリスト検証・内部ネットワークへのアクセス禁止が実装されているか

## ハードコードシークレット検出パターン（grep 用）

```regex
(api_key|apikey|api-key|secret|password|passwd|token)\s*=\s*["'][^"']{8,}["']
sk-[a-zA-Z0-9]{48}        # OpenAI API key
AKIA[A-Z0-9]{16}          # AWS Access Key
-----BEGIN.*PRIVATE KEY   # 秘密鍵
```
