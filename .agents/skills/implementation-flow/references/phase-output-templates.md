# Phase 別出力テンプレート

implementation-flow の各 Phase で生成する成果物のテンプレート。

---

## Phase 0: 作業種別記録テンプレート

```markdown
# 作業種別記録: [機能名]

## 判定結果
- **作業種別**: greenfield-new | extend | modify-breaking | legacy-integration | bug-fix | perf-only
- **実行パス**: Full | Lite | Redirected
- **リダイレクト先**（該当時）: bug-triage-fix | improve-flow | なし
- **検証対象パッケージ**: backend | frontend | both（本リポジトリのデフォルトは both）

## Docs Sync 設定（Phase 0d）

| 項目 | 記録 |
|:-----|:-----|
| **Docs Sync** | 有効 / 無効（理由） |
| **Docs Root(s)** | specs / docs / specs+docs |
| **マッピング参照** | INVENTORY.md パス、または「README インデックス + 慣例」 |
| **ADR 永続化先** | 例: specs/backend/decisions/ |

## 判定根拠（4 問）

| # | 質問 | 回答 | 根拠 |
|:--|:-----|:-----|:-----|
| 1 | 再現可能な不具合か？ | Yes / No | [期待 vs 実際、再現手順] |
| 2 | 新機能なし・改善のみか？ | Yes / No | [改善対象の説明] |
| 3 | 既存コードベースへの変更か？ | Yes / No | [新規プロジェクトか既存追加か] |
| 4 | 契約破壊 / レガシー統合か？ | [該当なし / 破壊 / レガシー / 非破壊拡張] | [API・型・DB の変更内容] |

## Lite Path スキップ記録（Lite Path の場合）

| Phase | 実行 | スキップ理由 |
|:------|:-----|:-------------|
| 1 | 実行 / 簡略化 | |
| 2 | 実行 / 部分 / スキップ | |
| 3 | 実行 / 簡略化 | |
| 4 | 実行 / 部分 / スキップ | |
| 5 | 実行 | |
| 6 | 実行 | |
```

### テスト戦略 ADR テンプレート

```markdown
# ADR-[番号]: テスト戦略 — [機能名]

## ステータス
Accepted

## コンテキスト
[機能のドメイン重要度、外部依存、テスト容易性の制約]

## モジュール分類（test スキル Step 1）

| モジュール | 分類 | テスト手法 |
|:-----------|:-----|:-----------|
| [utils/xxx] | ドメインモデル / アルゴリズム | TDD（単体） |
| [hooks/xxx] | コントローラ | 実装後（統合/振る舞い） |
| [components/xxx] | コントローラ | 実装後（振る舞い） |

## テスト・ピラミッド配分

| 層 | 目安 | 対象 |
|:---|:-----|:-----|
| 単体テスト | 多数 | utils, services のドメインロジック |
| 統合テスト | 中程度 | API route, hooks, Container |
| E2E | 少数 | 最重要ユーザーシナリオのみ |

## テストファイル配置規約

- Backend: `backend/tests/unit/[module].test.ts`
- Frontend: `frontend/src/[path]/[name].test.ts`

## 判断
[ドメイン層 TDD + コントローラ層実装後テストを採用する理由]

## 影響
- [カバレッジ目標]
- CI / QE 検証コマンド例:
  - `cd backend && npm test && npm run build`
  - `cd frontend && npm test && npm run lint && npm run build`
```

├── types.ts                  # 型定義（タグ付きユニオン）— TDD 対象外

├── utils/

│   ├── [name].ts             # ビジネスロジック — TDD

├── hooks/
│   ├── use[Name].ts          # カスタムフック — 実装ファースト
│   └── use[Name].test.ts     # 振る舞いテスト（実装後）
├── components/
│   ├── [Name].tsx            # Presentational
│   ├── [Name].test.tsx       # 振る舞いテスト（実装後）
│   └── [Name]Container.tsx   # Container
├── styles/
│   └── [name].css
├── pages/
│   └── [name].tsx
└── index.ts                  # Re-export
