## 岱明中

### ジュニア実績サマリ

- 女: 36:52（12位）。想定34:54・6位から大きく下振れ。
- 男: 44:23（14位）。想定44:22とほぼ一致。南関に8秒差。

### 想定オーダー（確定）

- 女: 1村上 / 2山﨑 / 3角田 / 4増岡 / 5高田
- 男: 1松野 / 2山本 / 3今村 / 4田上 / 5–6 **未決**

### 展開シナリオ

**女子**
- 1区村上はジュニア9:58。荒玉3kmではさらに厳しい想定。出遅れからの追い上げ型になりやすい。
- 2区山﨑（ジュニア4区9:05）は短い1.855kmでも楽観しない。オープンの角田9:02と同帯のスタミナ感。
- 3–4区角田・増岡はジュニア／オープンとも約9分。差が小さい＝どこで離されてもおかしくない。
- 5区高田はジュニア2区8:49だが練習不足。3kmアンカーは勝負区間というより耐え区間。
- **対南関**: ジュニア1:25差。南関の上がりを前提に、差を縮めるなら1区の立て直しと中盤の崩し防止が必須。

**男子**
- 1–2区はジュニアで南関と同帯（松野9:41／山本8:34）。出だしで離されないのが最低ライン。
- 3区今村は区間8位8:27。ジュニアでは南関に対しここで追い上げ。荒玉でも勝負区間候補。
- 4区田上は安定感が最大の武器。ジュニア5区8:26。荒玉4区3kmでも崩さない想定。
- 5–6区が未決のため、総合上位（附・南関）を狙うなら10分切り層の起用が鍵。層が薄いと附との1分差は埋まらない。
- **対南関**: 8秒。2区山本 vs 大木の再戦がポイント。**対附**: 草野2区8:07級の爆走に対し、差を広げさせすぎないことが目標。

### リスク

- 女子全体のスタミナ／メンタル。村上のイメージ払拭。
- 男子5–6人目不足。病み上がり松野の本番仕上がり。
