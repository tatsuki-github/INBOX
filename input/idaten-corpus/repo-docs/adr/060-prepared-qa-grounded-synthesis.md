# ADR 060: 想定QAとKG検索資料からの回答生成

- Status: Accepted
- Date: 2026-10-03
- Supersedes: ADR 059 の想定QAを直接返すオンライン回答方針

## Context

「2025年の中体連駅伝女子の岱明の詳細結果。区間タイムと区間順位と通過タイムと通過順位」のような質問では、短い総合結果QAが選ばれると必要な項目が欠ける。検索索引への成績表転記も区間順位・通過順位を落としていた。

## Decision

1. LLMが設定されている場合、想定QAの一致は回答候補と根拠パスとして扱う。候補の回答本文を直接返さず、KG検索の参照資料とQA根拠資料の本文を取得し、両方をLLMへ渡す。
2. KGのヒントは検索経路のために使い、事実の根拠は参照先の本文とする。生成済みFAQを検索根拠から除外し、FAQが自分自身を裏付けないようにする。
3. LLMは質問の年・大会・性別・学校・区間に合う資料から必要項目を補う。同一条件で候補と資料が矛盾すれば一次資料を優先し、解消できない矛盾や未収録の項目は未確認とする。順位を推測しない。
4. 区間詳細と総合結果QA、成績表の検索索引には、区間タイム・区間順位・通過タイム（累計）・通過順位を保存する。値が無い場合は未確認と明記する。
5. LLM未設定時は出典監査済みのQAで応答する。LLMの呼び出しに失敗した場合はエラーを返し、静的QAに黙って戻さない。
6. 動的なヘルプ・コース画像・動画の回答、確認質問、個人情報と報酬に対する既存の制限は維持する。

## Verification

区間詳細へのルーティング、5区間の4項目の出力、不完全なQAとKG参照資料の両方がLLMに渡ること、LLM生成結果を返すこと、生成失敗、FAQの自己参照除外を回帰テストで確認する。成績表から索引を再生成する際に順位を保持することも検証する。
