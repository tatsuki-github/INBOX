# ADR 056: 荒玉駅伝 SB 区間予想（5ヶ月鮮度・歴代キャリブ）

- Status: Accepted
- Date: 2026-09-27

## Context

なごみ／ジュニア駅伝では区間オーダー×SB換算の予想パイプラインがあるが、荒玉には未整備だった。
荒玉は区間距離が長く差が大きく、トラックSBの楽観が女子で顕著（ジュニア2026岱明: 予想34:54→実績36:52）。
公式オーダー未着でも岱明確定区間とジュニア地区結果で部分予想・展開シナリオを先に残したい。
データ（SB・直近駅伝）だけでは拾えない監督・コーチの文脈（病み上がり、スタミナ不安、覚醒期待など）もある。

## Decision

1. **生成**: `scripts/generate_aragyoku_ekiden_sb_preview.py`
   - なごみ換算式を再利用し、[docs/aragyoku-ekiden-distance-definitions.md](../aragyoku-ekiden-distance-definitions.md) の2024以降距離で比例。
   - 男子3000m閾値は30秒（ジュニア踏襲）。
   - **仮オーダー**: `PROVISIONAL_ORDERS` シード＋`get_provisional_orders` で荒玉地区の複数校を全区間埋める（公式未着時）。
     岱明女子・男子1–4は監督確定、男子5–6と他校はジュニア／所属SB上位の仮置き。
     **クラブ→学校分配**は `input/arato_tamana_report.yaml` の
     `school_analysis_affiliation_overrides` / `school_analysis_athlete_affiliation_overrides` を正本とする
     （金栗PROJECT→菊水、玉名アスリーツ→玉陵、ATRCは選手別＝今村→岱明・石川/米谷→長洲・default→荒尾四、など）。
     クラブ単位の一括校置きはしない。
   - 出力はなごみ同型（総合順位・通過順セル・チーム別詳細）。男女別 MD も dual-write。
   - **欠測は補完しない**（中央値なし）。実SB／直近駅伝で全区間そろったチームのみ総合順位に載せる。
   - **同一選手の複数区間は禁止**（`legs_from_ranked_athletes`）。異体字・OCR1文字差
     （例: 河野壮大／壮太、森絢恵／惠）も同一選手とみなす。候補不足の区間は空欄＝欠測。
   - 玉名高附女子は所属=玉名附中の実SB選手のみ（他校同姓同名の誤混入を排除）。
   - 女子仮置きは**1区・アンカー（5区）に校内エース**を置く（岱明確定も同型）。
   - 男子仮置きは**最速→1区・最遅→5区・次点遅→2区**、残りは若い区間番号から
     （`legs_from_ranked_athletes`）。候補が区間数より多いときは**最速 n 名だけ**を出走枠にし、
     プール全体の最遅を誤って2/5区に載せない。**岱明男子のみこの並べ替えをしない**
     （1–4監督確定＋5–6仮を維持）。   - **南関女子**: なごみα＋控えの原賀美和（β 7:53）を採用。βで遅い稗島（9:07）は仮主将オーダーに置かない。
     - **玉名中／荒尾三中女子**: 前年A＋Bチーム実績（`PRIOR_YEAR_B_TEAM_RETURNERS`）で仮オーダーを固定。
       玉名は1清藤・2亀木・3川原・4結菜・5水本（川原は今年フォーム落ちで1/5区外＝中盤ライン。
       亀木／結菜は姓名一部未確認）。
       荒尾三は1庄山・5福島（アンカー）・2平・3内野・4佐藤（庄山は1500 4:39・なごみ6:28、福島は前年1区→5区）。
     - **荒尾第四中男子**: 前年A復帰＋SBに、なごみOPの藤井祐吏を入れて全区間を揃える
       （`LOCKED`。配置規則で藤井は5区。松岡・浦本は控え。なごみタイムは `RECENT_EKIDEN_MARKS`）。
2. **SB鮮度**: `load_sb_index(..., freshness_days=152)`（≒5ヶ月）。
3. **直近駅伝ブレンド**: `RECENT_EKIDEN_MARKS` を距離比例し、半減期21日でトラックSBと加重平均。
   直近駅伝がある選手は歴代`LEG_BIAS_SEC`を重ねない。
   **女子**は `WOMEN_SB_WEIGHT_SCALE=0.15`、**男子**は `MEN_SB_WEIGHT_SCALE=0.20` で SB を抑える。
   **不調レースは意図的に非注入可**（例: 小倉由宇のなごみ10:30。Jr CS 8:48@2.6km のみ注入）。
   **去年・一昨年の荒玉**（2025は学年1–2、2024は学年1のみ＝今年度も在籍し得る選手）は
   陸上部SBが無くても校プールに入れ、区間タイムを `PRIOR_YEAR_COURSE_WEIGHT` の固定重みでブレンドに残す
   （一昨年のみの選手は `PRIOR_YEAR_MINUS_2_WEIGHT`。同一選手に複数年がある場合は**最新年のみ**ブレンド）。
   **今年度中学生のみ**: 同校同名の学年履歴で (1) 最新出場の繰り上げ学年>3、または
   (2) 過去学年から見て最新出場時点で既に卒業相当（幽霊データ）なら除外。
   `EXCLUDED_GRADUATES` で人間オーバーライド可（例: 天水・山本悠斗）。
   卒業者除外で校プールが最低人数未満ならその校は仮オーダー非掲載（例: 長洲男子・米谷慶吾卒業後）。
   **前年コース伸び**: 前年荒玉がある選手は `apply_yoy_course_growth` で前年比例×(1−伸び率)をブレンドより速い場合に採用。
   今年フォームが同程度〜良いときデフォルト 2%（実測改善は最大 5%）、明らかに遅いときは未適用。前年のみは 1.5%。
   **事実エビデンス**: 各選手の予想セル／エビデンス列に、使った事実を記載する
   （SB種目・記録・日付、駅伝の大会名・実測・距離・比例・重み、前年伸びのベースマーク）。
   推測・印象だけの文言は入れない。
4. **男子1区下限**: `MEN_LEG1_FLOOR_SEC=8:50`。
   **男子3000mトラック優先**: `apply_men_track_3000m_cap`。3000m SB があるのに
   前年荒玉の距離比例や区間バイアスで予想が遅すぎる場合、区間比例+`MEN_TRACK_3000_ROAD_ADD_SEC`（5s）を上限に引き上げる。
   前年荒玉のみ（今年なごみ/Jr無し）の男子は SB 重みを抑えずトラックを主にする。
5. **人間考慮（男女別）**:
   - `人間考慮_女子.yaml` / `人間考慮_男子.yaml`（Drive・コーパス dual-write）。
   - `memo`（自由記述）＋ `adjustments`（`athlete` または `team`+`leg`）。
   - `delta_sec` / `set_sec` / `min_sec` / `max_sec` をデータ予想の**後**に適用。
   - 既存 YAML は再生成で上書きしない（欠落時のみシード）。
   - 予想 MD 冒頭にメモと調整表を掲載。
   - 例: 玉名・川原芽吹 `delta_sec: +45`（今年フォーム落ちで前年伸びを打ち消し）。
   - 例: 南関男子は `team: 南関中` のみ（全区間）`delta_sec: +20`（直近フォーム上がらず）。
     `team` のみ指定は校の全区間に適用（`team+leg` より広い）。
   - 例: 岱明・松野凛空 `set_sec: 9:20`、田上颯人4区 `set_sec: 9:40`、
     山﨑莉奈2区 `set_sec: 6:50`（コーチ実力線の絶対固定）。
   - 例: 長洲女子は猿渡1区・村里2区・濱北3区・山川4区・中村5区（アンカー）固定。
6. **キャリブ**: `scripts/calibrate_aragyoku_sb_preview.py`。
7. **展開**: `校別展開予想.md` / `仮区間オーダー.md`。
   `校別展開予想.md` は SB 総合順位と **前年荒玉成績** から自動生成する。
   - 昨年同順位差: 今年N位予想 − 昨年N位実績（負＝昨年同順位より速い）
   - 同校差: 今年予想 − 昨年同校実績
   - 「今年どうなるか」の短い見立てと校別区間予想一行
   - 総合順位表の各区セルは `選手名 (通過順)通過 / (区間順)区間`（`fmt_leg_pred_cell`）

## Consequences

- 人間 YAML を編集 → スクリプト再実行で予想が追従する。
- データ層と人間層が分離され、AI/キャリブ更新でもメモが消えない。
- `RECENT_EKIDEN_MARKS`・人間 YAML は大会後の手動メンテが必要。
