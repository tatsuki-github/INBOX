# ADR 019: 大会フォルダ・結果ファイル命名規約

## 状況

`drive-text/大会/` のクラブ結果ファイル名が大会ごとにバラついていた（`結果.md` / `いだてん岱明結果.md` / `{大会名}_岱明の結果.md` / `結果/` 配下など）。
KG builder と Q&A の path boost は **`岱明の結果.md`** を前提にしているため、別名だと preferred refs とスコアが外れ、結果があるのにコーチ定型に落ちることがあった。
また 2025 荒玉フォルダ名に「荒玉」トークンがなく、`meetDriveTokens("aragyoku")` と不一致だった。

## 決定

1. **正規名**: クラブ結果は大会フォルダ直下の `岱明の結果.md` のみ。出場・計画も `岱明の*` に統一。
2. **フォルダ**: `{MMDD}_{大会名}` を維持し、検索トークン（荒玉など）と別名を括弧併記で含める。
3. **other 大会**: `meetDriveTokens("other", query)` がクエリからパス語（例: 玉名市民マラソン）を抽出し drive-text を先頭ブーストする。
4. **正本**: `input/external/drive/shared/大会/` をリネームし、corpus を同期。Google Drive 本体の改名は別運用。
5. **文書**: `input/idaten-corpus/drive-text/大会/NAMING.md` を規約の入口とする。

## 不採用

| 案 | 理由 |
|:---|:-----|
| ファイル名に大会名を毎回プレフィックス | フォルダ名と二重になり、正規名が割れやすい |
| Drive 上の全 PDF 名まで改名 | 公式 OCR 名は外部由来。クラブ要約だけ正規化する方が費用対効果が高い |

## 結果

- 全大会のクラブ結果が `岱明の結果.md` に揃う
- KG / rag 再生成後、玉名市民マラソン等でも結果パスが preferred になる
- 関連: ADR 016, ADR 017
