# Phase 1: 事実エビデンス記載（要求）

## ユーザーストーリー

コーチとして、区間オーダー予想の各選手タイムについて「どの記録からその秒数になったか」を事実で確認したい。なぜなら印象だけの備考では検証・議論できないから。

## 受け入れ条件

1. 予想タイムがある全区間で、エビデンス列に `→予想M:SS.s` が付く
2. トラックSB由来の場合、種目・記録・日付（あれば）と換算式・区間距離が記載される
3. 直近駅伝がある場合、大会名・実測・距離・日付・区間比例・重み・加重結果が記載される
4. 前年コース伸びを適用した場合、前年マーク事実と伸び率・採用タイムが記載される
5. 推測・印象のみの文言（例: 「直近駅伝加味(荒玉2025)」だけ）は出さない
