# Phase 1（簡略）: 荒玉 SB 予想 — 要求分析

## ユーザーストーリー

コーチとして、荒玉駅伝の区間オーダーに SB ベースの区間／総合予想を付けたい。なぜならジュニア結果で他校との差が見えた今、本番に向けた展開判断に数値とシナリオが必要だから。

## 受け入れ条件

1. 5ヶ月鮮度の SB のみで岱明区間予想が MD/coverage に出る。
2. 男5–6区は空欄のまま。
3. ジュニア荒玉地区結果と校別展開予想 MD がある。
4. 歴代キャリブで LEG_BIAS_SEC が埋まる。
5. ADR 056 がある。
