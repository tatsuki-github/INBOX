# 調査レポート: なごみ区間オーダーを金栗駅伝から分離する

## ユーザーストーリー

保護者・指導者として、なごみ駅伝の「岱明の1区は誰」「オーダーを見せて」に正しい当年オーダーで答えたい。なぜなら明日の大会なのに金栗駅伝や金栗記念のメタデータが返ると現場で使えないからだ。

## 受け入れ条件

1. [ ] 「なごみ駅伝の岱明男子1区は誰？」のオフライン根拠に `区間オーダーリスト` があり、`山本` と `哲瑠` が出る
2. [ ] 同上の sources に `金栗駅伝`・`金栗記念`・`.meta.json` が先頭に来ない
3. [ ] `detectMeetKind("金栗駅伝の日付は？")` は nagomi ではなく other、`なごみ駅伝` は nagomi のまま
4. [ ] 「案浦は何区走った？」は区間選手質問として荒玉正本へ寄る（`を` なし）
