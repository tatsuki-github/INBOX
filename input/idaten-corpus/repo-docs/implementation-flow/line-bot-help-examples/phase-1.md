# 調査レポート: LINE bot 使い方・質問例

## ユーザーストーリー
保護者・指導者として、LINE ボットの**使い方と聞き方の例**を知りたい。なぜなら初めてでも荒玉駅伝や練習・記録を正しく質問できるからだ。

## 受け入れ条件
1. [ ] 「使い方」「ヘルプ」「このボットは何ができる？」「質問例」等で canned ヘルプが返り、LLM/retrieve を呼ばない
2. [ ] ヘルプ文面に**個人の実名が無い**（プレースホルダ 〇〇 は可）
3. [ ] 質問例の**過半が荒玉駅伝**関連で、かつアプリ網羅（日程・結果・区間・記録・ペース・分析・コース動画・結果ボード・他大会/練習/結果URL/SB の聞き方・スコープ外）を含む
4. [ ] eval-200q の「このボットは何ができる？」が引き続き PASS（練習|大会|記録|いだてん のいずれかを含む）

## 受け入れ条件 → テストマッピング

| # | 受け入れ条件 | テスト種別 | 対象層 | テスト意図 |
|:--|:-------------|:-----------|:-------|:-----------|
| 1 | ヘルプ意図で canned | 単体 TDD | canned / answer | matcher + short-circuit |
| 2 | 個人名なし | 単体 | canned | 禁止リスト・実名パターン無し |
| 3 | 荒玉中心・網羅 | 単体 | canned | 必須フレーズ・カテゴリ |
| 4 | eval 互換 | 単体 | canned | any_of 語を含む |
