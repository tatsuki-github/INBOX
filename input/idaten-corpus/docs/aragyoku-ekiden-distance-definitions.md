# 荒玉駅伝 区間距離定義（質問回答・分析用の正本）

荒玉駅伝の区間距離を年度別に扱うときは、以下の定義を優先する。

## 適用ルール

- 年度別の駅伝距離を計算・説明するときは、この定義を優先する。
- 既存の文字起こしJSONにある一律の男子「3km・2km×4・3km」定義は、年度差を表現できないため、この定義で補正して扱う。
- 予測式・実績比較では、必ず性別・年度・区間の組み合わせから距離を引く。
- これは荒玉駅伝の距離に関する運用上のナレッジグラフ定義であり、他大会へは適用しない。
