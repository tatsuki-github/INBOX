# ADR 021: 曖昧な自己ベスト質問には具体的な質問例を返す

## 状況

LINE では送信者を選手マスタに紐づけていない。「自分の自己ベストは？」は誰の・どの距離かが不明なため、
RAG が誤った選手の記録を返したり、コーチ定型に落ちたりする。

## 決定

1. `matchClarifyAnswer` が自己ベスト／SB／PB 系で **選手名が無い** 質問を検出する。
2. LLM・検索の前に短文で具体例（名前＋距離付きの質問文）を返す。
3. 名前付きの具体質問（例:「今村昇磨の1500m自己ベストは？」）は通常の RAG へ進む。

## 不採用

| 案 | 理由 |
|:---|:-----|
| LINE userId → 選手名マッピング | 未整備。本スライス外 |
| LLM に例を生成させる | 遅延・幻覚。テンプレで十分 |

## 結果

- 曖昧な自己ベスト質問で「例: …」が即時返る
- 関連: ADR 015, ADR 020
