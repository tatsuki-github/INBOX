# ADR 013: 荒玉女子駅伝の氏名・学年を年度CSVで照合する

## 状況

荒玉女子駅伝の結果画像は、文字起こし後に原画像との目視照合を行っていたが、
字体の近い漢字を中心に誤認が残っていた。2012〜2026年度の中学生記録CSVが
利用可能になり、学校・学年・前後年度の在籍・トラック走力を組み合わせて
同一選手を照合できるようになった。

## 決定

1. 駅伝画像と同年度CSVの表記が競合し、学校・学年・前後年度・走力から
   一意に同一選手と判断できる場合はCSV表記を優先する。
2. CSVに氏名がないだけでは駅伝側を変更しない。
3. Unicode置換文字 `�` を含むCSV行は補正根拠に使わない。
4. トラック記録はCSVファイル名の年度を正本とし、駅伝と同じ年度だけを表示する。
5. レポート対象種目は800m・1500m・3000mとし、1000m列は表示しない。
6. 各補正の旧値・新値・CSV一致行数・採用根拠は
   `input/aragyoku/women_top4_csv_reconciliations.json` に保存し、
   生成時に元CSVとの一致を検証する。

## 今回の照合結果

- 氏名27件: 2012年8件、2013年5件、2015年3件、2016年2件、
  2017年2件、2018年4件、2019年1件、2023年2件
- 学年6件: 2013年1件、2016年2件、2019年1件、2024年1件、2025年1件（計33セル）
- 2012年の訂正:
  - 西澤弥乃 → 森澤彩乃
  - 大濱志歩 → 大道志歩
  - 嶋村梨那 → 嶋村里恩
  - 岱明 前田明日香 → 前田明佳里（2013年CSV・駅伝で継続確認）
  - 岱明 中川菜月 → 中川葉月（2013年岱明ロスターと一致）
  - 岱明 鎌田愛貴 → 植田愛美（2012〜2013年CSVで継続確認）
  - 玉名 猿渡睦月 → 磧結里（2012年CSV・2013年駅伝で継続確認）
  - 荒尾海陽 吉岡愛希/愛馨 → 吉岡愛琴（2014年CSVで継続確認）
  - 玉名 本田結里 → 本田悠薫（2018年CSV・2019年継続確認）
  - 腹栄 田上遥 → 田川華妃（2018年CSV・2019年駅伝で継続確認）
- 濱本麻那など複数候補が残る表記は変更していない。

## 不採用

| 案 | 理由 |
|:---|:---|
| 編集距離だけで自動補正 | 同校・同学年に複数候補がいる場合に別人へ誤補正する |
| CSVにない駅伝選手を削除 | トラック大会への不参加は駅伝記録の誤りを意味しない |
| 日付の暦年でCSVを再分類 | 元データのシーズン区分を壊す |

## テスト戦略

- 単体: 全15年度ファイル必須、女子・中学生のみ採用、氏名・学年補正値
- 統合: 補正マニフェストの根拠年度CSVと生成結果が一致すること
- 回帰: JSON・CSV・PDF再生成、1000m列の非表示、全テスト
