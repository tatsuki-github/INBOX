# ADR 005: 大会2日前の RP 刺激

## Status

Accepted

## Context

大会の2日前にレースペース（RP）の短い刺激を1本入れるのが岱明の運用ルールである。例:

- 1500m → 900m×1（または 1000m×1）
- 800m → 600m×1
- 連続疾走は **最大 1000m**、本数は増やさない

既存の `next_race` は「翌日の記録会/選手権」だけを見ており、2日前の刺激も、種目（800/1500）も、カレンダー上の「県中体連」「総合体育大会」も拾えない。練習会や人権教育研究大会を大会扱いすると誤検出になる。

### 作業種別（implementation-flow Lite Path）

- **種別**: `extend`（既存 AI 生成への非破壊追加）
- **検証**: Python / pytest（`scripts/ai/` + `tests/`）
- **Docs Sync**: 有効（`docs/`、ADR 正本 `docs/adr/`）
- **スキップ**: Phase 2/4（UI なし）。Phase 1/3 は簡略化

## Decision

1. **検出**は決定論。タイトル/説明に選手権・記録会・総合体育大会・中体連等があれば大会。練習会・研究大会・振込/返金は除外する
2. **種目**はタイトルと description からパースする（実カレンダーの県中体連は説明文に 800m/1500m がある）
3. **距離マップ**（1本、≤1000m）:

   | 種目 | 刺激 |
   |---|---|
   | 800m | 600m |
   | 1500m | 900m（クエリに 1000 があり 900 が無いとき 1000m） |
   | 1000m | 900m |
   | 3000m 以上 | 1000m |
   | 100/200/400 / 4×400 | 300m |
   | 不明 | 900m（確認チェックリスト） |

   800 と 1500 が混在するときは **短い刺激（600m）** を既定にし、1500 組は手で 900/1000 に変えられる旨を notes に書く
4. **適用条件**: 夕練、かつ 2 日後が大会、かつ翌日が練習会/記録会でない。クエリが「ジョグのみ」等なら上書きしない
5. テンプレ `pre-race-rp-{300,600,900,1000}` をカタログに追加。生成器は `--date` の文脈でこのテンプレを優先する
6. 現場1枚は「2日後」行・切上げ「1本のみ」・種目確認チェックリストを出す。信頼度は `review`
7. 週次フォールバックも同じカレンダー規則で上書きする

## Consequences

- `--date 2026-07-16`（県中体連の2日前）は 800+1500 混在のため 600m×1 RP になる
- LLM が本数や 1000m 超を足した場合は `validate_pre_race_practice` が落とす
- 選手名は書かない（ADR 004 と同じ）

## Alternatives Considered

- 既存 `interval-300-rp`（300m×6-10）を流用: 却下 — 本数が刺激ではなく本練習になる
- 翌日（1日前）にも RP: 却下 — 既存の「翌日は追い込み禁止」と衝突
- 1500m 既定を 1000m: 却下 — ユーザー例の先頭が 900m。1000m は明示時のみ
