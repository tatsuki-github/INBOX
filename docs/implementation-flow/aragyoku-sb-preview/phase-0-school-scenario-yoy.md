# Phase 0: 校別展開に昨年同順位差・今年予想（Lite extend）

## 作業種別

| 項目 | 値 |
|:---|:---|
| 種別 | `extend` |
| 技術 | Python + unittest（UI なし） |
| Docs Sync | ADR 056 / `校別展開予想.md` |

## ゴール

`校別展開予想.md` に次を追記・自動生成する。

1. **昨年同順位との差**: 今年N位予想タイム − 昨年N位実績
2. **同校昨年差**: 今年予想 − 昨年同校実績（ある場合）
3. **今年どうなるか**: SB総合順位に基づく短い展開見立て
