# Phase 0: 卒業生除外 — 今年度中学生のみ（Lite extend）

## 作業種別

| 項目 | 値 |
|:---|:---|
| 種別 | `extend` |
| Docs Sync | ADR 056 |

## ゴール

山本悠斗など**中学卒業済み**を仮オーダー／プールから除外し、**今年度在籍の中学生のみ**を対象にする。

## スキップ

Phase 2/4。

## 背景

- 天水・山本悠斗: 2023(3)→卒業済。2025成績表は誤って(1)のため単年フィルタをすり抜けていた。
- 長洲・米谷慶吾: 2025(3)→今年度卒業。除外後プール1名のため男子長洲は非掲載。
