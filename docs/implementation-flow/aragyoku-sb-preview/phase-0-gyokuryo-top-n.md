# Phase 0: 玉陵遅延 — 男子は最速N名から配置（Lite extend）

## 作業種別

| 項目 | 値 |
|:---|:---|
| 種別 | `extend` |
| Docs Sync | ADR 056 |

## ゴール

校プールに今年度中学生を**全員**載せたうえで、仮オーダーは**最速の区間数分**だけを選び、その中で遅→5・次遅→2する。全プールの最遅を誤って出走枠に入れない。

## 背景

玉陵男子が 60:04 と遅い主因は、12名プールの最遅（五郎丸・三次）が2/5区に入っていたこと。内野・松島など上位層が落選していた。

Phase 2/4。
