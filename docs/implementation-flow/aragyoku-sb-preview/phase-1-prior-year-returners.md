1. 荒玉2025 transcript の学年1–2が校プールに入る（例: 佐藤央琉→岱明）。
2. 前年区間タイムが `RECENT_EKIDEN_MARKS` に `荒玉2025` として入り、ブレンド注記に出る。
3. 男子も直近駅伝があるとき SB 重みを抑える（`MEN_SB_WEIGHT_SCALE`）。
4. 岱明男子3区（今村）のデータ予想がおおよそ9:50未満（前年9:38＋Jr寄り）。
5. unittest が通る。
