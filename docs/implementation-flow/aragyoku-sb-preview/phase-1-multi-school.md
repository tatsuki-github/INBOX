# Phase 1（延長）: 多校・全区間仮置き

## ユーザーストーリー

コーチとして、公式オーダー未着でも荒玉地区の他校を含む全区間のなごみ／ジュニア同型予想を見たい。順位・通過順・チーム詳細まで埋めて当日シミュレーションしたい。

## 受け入れ条件

1. 女子は参加校すべて5区間に選手名があり、男子は6区間に選手名がある（仮置き可）。
2. 出力 MD がなごみ同型（参考総合順位・完全記録順位・通過順セル・チーム別詳細）である。
3. 岱明女子・男子1–4は確定、男子5–6と他校は※仮と明示される。
4. 欠測補完は区間別中央値（距離差対応）。
5. `tests/test_aragyoku_sb_preview.py` が通る。
