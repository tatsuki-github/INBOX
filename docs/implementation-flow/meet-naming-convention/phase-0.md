## ゴール

全大会でクラブ結果ファイルを `岱明の結果.md` に統一し、フォルダ名に検索トークン（例: 荒玉）を含め、KG / Q&A が大会結果を確実に辿れるようにする。

## 命名規約（確定）

| 種別 | 規約 |
|:-----|:-----|
| 大会フォルダ | `{MMDD}_{大会名}` または `{MMDD}-{MMDD}_{大会名}`。別名がある場合は括弧で併記（例: `荒玉中体連駅伝（玉名荒尾）`） |
| クラブ結果 | 大会フォルダ直下の **`岱明の結果.md`**（唯一の正規名） |
| 出場・計画 | `岱明の出場.md` / `岱明の出場予定.md` / `岱明の参加計画.pdf.md` |
| 公式結果 OCR | `結果_*.pdf.md` または `結果/` 配下の種目別ファイル（現状維持） |
