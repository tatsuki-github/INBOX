# 岱明中 荒玉中体連駅伝（2026-10-14）第一ピーク向けトレーニング計画

**対象期間**: 2026-08-09 〜 2026-10-14（約9.5週）  
**第一ピーク**: 2026-10-14 荒玉中体連駅伝（予備日 10-15）  
**次峰の位置づけ**: 県中学駅伝 11-06 は第二峰候補。本計画は 10-14 を第一峰として設計する。  
**データ根拠**: `input/events.2022–2026.yaml` のいだてん岱明練習記録、2026年夏の朝夕練スケジュール、選手レース結果、指導メモ、`tmp/norwegian_method_summary.md`（Bakken *The Norwegian Method Applied* 要約）

## A. 結論

今回の戦略は、**「強すぎる練習を増やす」ではなく、「制御可能な閾値付近の刺激を、怪我なく繰り返して積み重ね、10月上旬に駅伝特異性を乗せ、大会前1週間で量を落として刺激だけ残す」**ことである。

- **中心刺激**: Golden Zone（閾値直下〜閾値付近）。岱明で既に馴染んでいる「遅め〜適正の300/600/900m」「組別ペース」「間は他組の時間」を、より意図的に強度管理して使う。
- **採用しないもの**: 成人エリート向けの**連日ダブルスレッショルド**、高頻度のVO2maxオールアウト、暑熱下での機械的ペース死守。
- **量の骨格**: 週5日基本、週5〜8セッション。平日朝練は原則4〜5kmジョグ（低強度）。夕練に週2回までの質練習。
- **最上位目的**: 10-14 で最高パフォーマンスを出しつつ、**将来の伸び代を損なわない**（指導メモ「伸び代について」と整合）。

### B-4. 課題（データから見える改善点）

1. **ジョグラップが日によって速すぎる**（例: 最終ラップ急加速）→ グレーゾーン化リスク  
2. **質練習が「レースペース寄り」になりやすい**（300mを速く積みすぎ）→ 回復コスト↑  
3. **暑熱下で本数・ペースを機械的に守りがち**になりうる  
4. **テスト・学校行事・欠席**で連続性が切れやすい → 代替ルール必須  
5. **個人差が大きい**（1500m 4:22〜5:55超）→ 絶対ペースより組別＋RPE必須

## C. ノルウェー式から採用する原則 / 採用しないもの

出典: Bakken *The Norwegian Method Applied*（リポジトリ内要約）。中学生・週走行時間の制約下で再解釈する。

### C-1. 採用する（中学生向けに翻訳）

| 原則 | エリート原文の意味 | 岱明への翻訳 |
|---|---|---|
| **最高の反復可能強度 × 最低コスト** | controlled threshold | 「終わった後に翌日も普通に動ける」質を週2回 |
| **Golden Zone** | LT直下、乳酸おおよそ2–3mmol、短いフレーズ可 | 300/600/1000mを**会話が短いフレーズで可能な努力**で |
| **Easy < 約70%HRmax** | グレーゾーン回避 | 朝練・回復ジョグは「会話しながら走れる」 |
| **Accuracy > Variety** | 刺激を散らさない | メニュー種を増やしすぎない。中心はGZ＋イージー |
| **筋肉系がボトルネック** | 心肺より腱・筋トーン | 強い日の翌日は必ず軽く。痛みは即休止 |
| **Micro-recovery付きインターバル** | 連続THより分割 | 既存の「セット＋他組待ち」を意図的に使う |
| **量を落とすが刺激は残す（テーパー）** | 質の短時間維持 | 最終週は本数半減、ペース感のみ残す |
| **疑わしいときは遅く** | When in doubt, slow down | 暑さ・テスト明け・脚重い日は設定を落とす |

### C-2. 採用しない / 限定的

| 手法 | 判断 | 理由 |
|---|---|---|
| **ダブルスレッショルド（同日AM/PMで閾値2回）** | **基本採用しない** | 中学生は睡眠・学校・成長・熱環境の制約が大きく、筋系コストが過大。例外は「朝ジョグ（易）＋夕GZ」のみで、朝を質にしない |
| **週3回以上の高強度** | 採用しない | 故障・オーバートレーニングリスク |
| **4.0mmol固定や乳酸必須運用** | 必須にしない | 測定が常時できない。RPE・会話・ラップ安定で代替 |
| **VO2maxオールアウト週次** | 稀（峰前の短刺激のみ） | 回復予測が難しく連続性を壊す |
| **大人の走行距離コピー** | しない | 男子でも週おおよそ25–45km程度を目安に個人調整 |

### C-3. 優先順位（本計画の意思決定階層）

1. **怪我・故障を防ぐ**（痛み・腫脹・明らかなフォーム崩壊は即中止）  
2. **継続して練習できる状態を維持**（睡眠・食欲・心理・学校生活）  
3. **有酸素能力（イージーの質と適量）**  
4. **閾値付近（Golden Zone）の反復可能刺激**  
5. **駅伝特異（区間距離・ロード・レースペース感）**  
6. **スピード／ランニングエコノミー（短い流し）**  
7. **10-14へのピーク合わせ（テーパー）**

**10-14 vs 長期成長**: 衝突時は **2（継続）＞7（ピーク）**。つまり「今大会のために壊す」はしない。ピークは「余力のある状態で刺激を残す」ことで作る。根拠が強いのは故障予防と継続性（指導実績・発達段階）。ピーク微調整の細部は不確実性が残る。

## D. 8/9〜10/14 のフェーズ設計

### フェーズ概観

```
8/9        8/24       9/14       9/28       10/6      10/14
 |-- P1 再始動 --|-- P2 蓄積 --|-- P3 移行 --|-- P4 特異 --|-- P5 テーパー --|
   暑熱・回復        GZ定着        レース活用      駅伝特化       刺激残し
```

### Phase 1: 再始動と暑熱適応（8/9–8/23）

| 項目 | 内容 |
|---|---|
| **目的** | 県中体連後〜夏前半の疲労を整え、朝夕のリズムを安定。暑熱下で「易しく長く／質は短く制御」 |
| **発達能力** | 有酸素土台、熱順化、筋腱の再負荷耐性 |
| **重点** | 朝ジョグ4–5km、夕ジョグ、週1–2の短いGZ（本数控えめ）、流し |
| **控える** | 長いレースペース、300mの速すぎる連発、同日二回の質 |
| **量** | 週おおよそ 25–40km（個人差大）。セッション週5–7 |
| **強度** | Easy 70–75%、質はGZ下限 |
| **回復** | 週2休（例: 火 or 木の片方＋日）。睡眠優先 |
| **次へのつながり** | 「翌日脚が動く質」を体感させ、P2で本数を増やす土台 |

**生理学的根拠（確度: 中〜高）**: 暑熱では同一ペースでも心拍・主観強度が上昇し、筋グリコーゲン消費と脱水が進みやすい。ペースより内部負荷（RPE/HR/会話）で管理する方が適応を損なわない。中学生は成人より熱ストレス耐性が個人差大。

### Phase 2: Golden Zone 蓄積（8/24–9/13）

| 項目 | 内容 |
|---|---|
| **目的** | 反復可能な閾値刺激の週間ボリュームを最大化（ただし中学生上限内） |
| **発達能力** | 乳酸処理、ミトコンドリア刺激、耐久性（durability）、エコノミー |
| **重点** | 週2 GZ（例: 火=短いインターバル、金or土=やや長いセット）。ロングジョグ週1 |
| **控える** | VO2max系、過度な坂ダッシュ連発、テスト週間の質追加 |
| **量** | 夏休み最終〜2学期開始。朝練は徐々に「必要な日だけ」。週 30–45km 目安 |
| **強度** | GZ中心。イージーを厳密に落とす |
| **回復** | 質の翌日はジョグのみ or 休み。9/9 前期期末を考慮し質を前倒し／軽減 |
| **次へのつながり** | なごみ駅伝（9/20）に「疲れすぎない走力」を持っていく |

**根拠**: Bakkenの中心命題は「閾値帯の蓄積」。中学生では成人のDLTHではなく、**週2回×20–35分相当のGZ時間**が現実的上限（確度: 中。個人差大）。

### Phase 3: 特異性への移行＋試運転レース（9/14–9/27）

| 項目 | 内容 |
|---|---|
| **目的** | 内部capacityを保ちつつ、ロード・区間距離・レース展開へ外部特異性を上げる |
| **発達能力** | レースペース持続、ペース感覚、精神的耐性、チーム走 |
| **重点** | なごみ（9/20）、必要ならジュニア駅伝（9/26）。間の練習は回復＋短いGZ |
| **控える** | レース週に新しい高強度メニューを足すこと |
| **量** | レース週は総量10–20%減 |
| **強度** | レースで高強度を消費。他日は易しく |
| **回復** | レース後48hは低強度。睡眠・栄養を明示指導 |
| **次へのつながり** | レース差分（失速・序盤突っ込み・暑さ）をP4の個別課題へ |

### Phase 4: 駅伝特異ピーク負荷（9/28–10/5）

| 項目 | 内容 |
|---|---|
| **目的** | 横島干拓を意識したロード持続＋区間シミュレーション。**最後の大きな負荷** |
| **発達能力** | 区間特異持久、集団走、ラスト1kmの余裕 |
| **重点** | 試走 or 区間ペース走、GZ長めセット（例: 1000+500、2000相当分割） |
| **控える** | 新しいスピード挑戦、オールアウト300m多本 |
| **量** | 計画期間中のピーク週（ただし故障リスクが出たら即減） |
| **強度** | GZ〜レースペース短時間。VO2は必要最小 |
| **回復** | 10/5前後を最後のハードデーにし、その後は下げ始める |
| **次へのつながり** | 超補償のための意図的卸载へ |

### Phase 5: テーパー（10/6–10/14）

| 項目 | 内容 |
|---|---|
| **目的** | 疲労を抜き、スピード感とペース感覚だけ残す |
| **発達能力** | 神経系の鮮度、自己効力感、チーム一体感 |
| **重点** | 短いGZ or レースペース断片、流し、軽いジョグ |
| **控える** | 長いジョグの積み増し、新たなポイント練習、記録会での全力（10/10長距離記録会は原則スキップ or 調整走） |
| **量** | ピーク週比 **40–60%減** |
| **強度** | 短い刺激は残す（RPEはやや軽めでも「軽いキレ」） |
| **回復** | 睡眠最優先。学校行事（合唱コンクールは10/23で本峰後）は干渉小 |
| **つながり** | 10-14 出走。予備日10-15も同設計 |

**テーパー根拠（確度: 高〜中）**: 持久系では量減＋強度維持（または短時間維持）が成績を落とさず疲労を減らす、という知見が一般的。中学生は成人より短いテーパー（7–10日）で十分なことが多い。

| 1 | **当日疲労・脚・フォーム** | 重い・左右差・着地音が鈍い → 強度↓ or 中止 |

| 3 | **会話** | E:普通に会話 / GZ:短いフレーズ / それ以上:速すぎ |
| 4 | **組別ラップ** | 均等ペース。ばらつき大なら設定見直し |
| 5 | **心拍**（任意） | E: 〜70%HRmax目安 / GZ: 約80–87%だが暑熱で上振れ→ペースよりHR・RPE優先 |
| 6 | **レースタイム換算** | 下記テーブル |
| 7 | **乳酸**（稀） | 取れるならGZおおよそ2–3mmol目安。必須ではない |

### G-3. 暑熱環境でのペース修正（重要）

| 条件 | 対応 |
|---|---|
| 気温高・湿度高、WBGT注意 | **設定ペースを捨て、RPE/会話を主指標に**。同一RPEならペースが落ちて正解 |
| 朝練 | 日の出直後でも無理しない。給水・帽子・短縮 |
| インターバル | 休憩を15–30秒延長。本数-20–30% |
| 「予定ペースに届かない」 | **失敗ではない**。内部負荷が予定に達していれば完了 |
| めまい・頭痛・異常な息切れ | 即中止、冷却、保護者連絡 |

**結論**: 暑熱下で機械的に設定ペースを守るのは**不適切**なことが多い（確度: 高）。

### G-4. レペの進め方（Bakken流の現場版）

1. 1本目は目標より**意図的に穏やか**  
2. 中盤で安定  
3. 最後だけ同じかわずかに速い  
4. 「もう1本いける」で終了が成功

## H. 代替メニュー・変更ルール

### H-1. 刺激の優先順位（削る順番）

予定が崩れたとき:

1. **最優先で残す**: 低強度の継続（短いEでも「完全ゼロ連続」を避ける）＋睡眠  
2. **次に残す**: 週1回の短いGZ（300m×4–6でも可）  
3. **残せるなら**: 流し2本（エコノミー）  
4. **削ってよい**: 2本目の質、ロングの距離、朝練、練習会の上乗せ  
5. **置き換え**: ロードGZ ↔ トラックセット、試走 ↔ 平坦路ペース走  
6. **完全休養**: 痛み、発熱、インフルエンザ等、強い倦怠、睡眠極端不足、オーバートレーニング兆候

### H-2. ケース別代替

| ケース | 代替 |
|---|---|
| **閾値予定だが疲労強い** | 本数半分 or 200m×6 or E＋流し。翌日に持ち越さない（持ち越し連鎖を防ぐ） |
| **暑熱で設定ペース不可** | ペース放棄、RPE5–6で本数減らして実施。それでも無理ならE |
| **学校行事で夕練不可** | 朝Eのみ or 家庭15–25分E。質は週内の別日へ**1回だけ**移動 |
| **一部選手だけ疲労** | グループ分け。疲弊組はEコース、元気組は予定質 |
| **前日が想定以上に負荷** | 翌日は自動的にE。質は48h後 |
| **なごみ/ジュニア後** | 48h質禁止 |
| **テスト週間** | 質は週1短いかゼロ。罪悪感を持たせない |
| **雨・雷** | 室内動きづくり＋ドリル。無理な外質なし |
| **指導者不在** | 書面のEメニューのみ。自主で強度を上げさせない |

### H-3. 「追加するなら何を削るか」

| 追加したい刺激 | 必ず削るもの |
|---|---|
| GZをもう1本 | その週のロング or 朝練2回 |
| レース出場 | 前後の質2回 |
| VO2的な速い300m | その週のGZ長セット |
| 坂 | 同日のトラック質 |
| 記録会 | その週のポイント1つ＋翌日E固定 |

**原則**: ポイント練習は**週2が上限**（レース週はレースが1を占める）。

## I. 疲労・故障・暑熱への対応

### I-1. 継続 vs 休息の判断

| サイン | 判断 |
|---|---|
| 軽い筋肉痛、やる気普通 | 予定通り〜少し軽く |
| 脚重い、睡眠不足、表情が暗い | 少し軽く / E変更 |
| フォーム崩壊、タイム崩壊、息が回復しない | 別メニュー（E） |
| 局所痛（骨・関節・鋭い痛み）、発熱 | **中止**。保護者・必要なら医療機関 |
| 塚原のように疲労骨折懸念の既往情報がある場合 | 早期に量と衝撃を落とす。走らない選択を褒める |

### I-2. 既存方針との整合

- 「痛みを我慢してまで走らせない」（メモ）を全フェーズで適用。  
- 「伸び代＝ローリスクの継続」（メモ）を、大会前の追い込み衝動に対するブレーキとする。

### I-3. 暑熱プロトコル

- 給水タイミングをメニューに組み込む（ジョグ3周ごと等）。  
- 無理な二重練習（朝質・夕質）は禁止。  
- 体調申告を練習開始時に1分で行う（脚・睡眠・のど・気分）。

## J. ピーキング・テーパリング

| 問い | 設計 |
|---|---|
| いつから駅伝特異性を高めるか | **9/14〜**（P3）。本格ロード特異は **9/29〜10/5** |
| 最後の大きな負荷 | **10/2（金）**（予備として10/3試走は低強度確認） |
| いつ量を減らすか | **10/6〜** 明確に削減 |
| 強度はどこまで維持するか | 短いGZ/RP断片は残す。長い持続は切る |
| 最終週に残すもの | 短い刺激、流し、動きづくり、チーム声出し |
| 最終週に削るもの | ロング、朝練、練習会の上乗せ、記録会全力、新しいドリル |
| レース前数日 | 10/11休、10/12極軽、10/13短刺激、10/14本番 |
| 神経系・スピード感 | 流しと短い加速をテーパー期間も週2–3回、ただし総量少 |

### テーパーの考え方（量↓・刺激は残す）

- 疲労物質・筋トーン・心理的圧を下げると、**すでに作った有酸素・閾値能力がレースで発現**しやすい。  
- 刺激をゼロにすると脚が鈍るため、**短い・速い・少ない**を残す。  
- 中学生は「練習しない不安」が出やすい → **「今日は弾丸を銃に込める日」**と意味づけし、量を削ることを自信に変える。

## この計画で最も重要な5つの原則

1. **壊さず続ける** — 痛みと過度な疲労の上にピークは載せない。  
2. **イージーを本当に易しく** — 朝練と回復日をグレーゾーンにしない。  
3. **Golden Zoneを週2、制御して反復** — 速く追い込む質より、翌日動ける質。  
4. **週の刺激は上限を決め、足すなら削る** — ポイント過多が最大のリスク。  
5. **10/6から量を削り、短い刺激だけ残して10/14に峰を合わせる** — 不安で走らない。
