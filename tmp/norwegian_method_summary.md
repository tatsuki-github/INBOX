# 第0部：序文・本書の構成

## 0.1 核心問い（1995年〜）

> **What is the highest intensity you can repeat, at the highest sustainable volume, week after week, for the lowest possible cost?**

| 原則 | 説明 |
|---|---|
| 規律 | 最大努力ではなく **controlled**（passive/cautious ではない） |
| セッション設計 | 適応を強制するほどハード、**数時間後に再び質の高いワーク**が可能 |
| 3要素 | **precision, restraint, continuity** — 複雑さではない |

## 0.2 ノルウェーメソッドの定義

- **固定中心**: 真の変曲点（inflection point）**直上**の狭い強度帯 — 閾値ワーク
- 刺激は強いが、**頻繁に繰り返せるほどコストが低い**
- セッション・周期化・負荷調整 — すべてこの中心に対して計画・監視
- **目標**: ワークアウトに勝つことではなく、回復ではなく**適応**として月年を通じた高品質ワークの蓄積

## 0.3 5,500乳酸テスト

- 自己・パートナー・ケニア（portable meter + test strips）
- 発見: ダブルスレッショルド、**頻度 > 強度**、制御可能な繰り返し
- Jakob Ingebrigtsen の世界記録にも本書のセッションが反映
- レクリエーション: 「易しすぎる」インターバル + 十分な頻度 = 最大利益

## 0.4 典型的失敗パターン

| 行動 | 結果 |
|---|---|
| イージーデーで速すぎ | グレーゾーン |
| ハードデーでも速すぎ | 疲労 > 適応 |
| 脚フラット・生存インターバル | 小さな怪我、自己不信 |

**原因**: タフさ不足ではなく **精度不足**

# 第I部：The Method（第1–4章）

## 第1章：閾値トレーニング — Golden Zone

### 1.1 Frognerparken 1998の教訓

- 冬: Ingrid Kristiansen グループ — 中間ペースで**「限界線」を観察**
- 夏: 13:22（5K）— 同グループから1分以上速い
- Ingrid: 「What on earth? I didn't see this coming.」
- **繰り返せる強度**で週を通じて静かなコストを避けた

### 1.2 閾値ペースと Golden Zone

| 用語 | 定義 |
|---|---|
| 閾値ペース | すべてが噛み合う日に**約1時間**持続可能なペース |
| 本書の「閾値トレーニング」 | **閾値の直上ではなく、直下** — sub-threshold / sweet spot |
| Golden Zone | 適応には十分ハード、**繰り返しには十分コントロール** |

### 1.3 Golden Zone 数値

| 指標 | 値 |
|---|---|
| 乳酸（well-trained） | **2.3–3.0 mmol/L**（個人差 2.0–3.5） |
| 心拍 | 最大の **80–87%** |
| 会話 | **短いフレーズ**は可能、完全な文は不可 |
| 翌日 | 脚は準備完了、重くない |

### 1.4 なぜ 4.0 mmol/L ではないか

- Mader (1970s): 4.0 = 教科書的閾値 — **個人差を無視**
- 5,500テストの結論: 4.0 を固定境界にせず、**個人定義点の 0.3–0.6 mmol/L 下**
- 保守的設定 → 3.0 mmol/L 付近に**より早く到達**

### 1.5 ケニア vs ノルウェー

| 観察 | ケニア | 西洋（当時） |
|---|---|---|
| 見た目の努力 | 3/4 effort、インターバル間会話 | 膝付き、HR max |
| レース | 圧倒的 | — |
| 乳酸 | **明らかに低い強度** | — |

2000年ウェブ記事（原文）:
> "You/your athlete should be approx. 0.3–0.5 below the LT on these sessions."

### 1.6 Golden Zone の5メカニズム

| システム | 十分な刺激 | 避ける過負荷 |
|---|---|---|
| **ミトコンドリア** | AMPK + カルシウムシグナル両方 | 単独volume/intensityでは不可 |
| **乳酸処理** | 曲線右シフト | クリアランス overwhelmed |
| **グリコーゲン** | 適度な枯渇 → 貯蔵容量↑ | 完全枯渇 → 回復数日 |
| **ホルモン** | 適応反応 | コルチゾール↑ → 睡眠・免疫 |
| **筋動員** | 高い絶対速度でfiber recruit | 機械的負荷 > 修復能力 |

### 1.7 筋肉系 = 真の制限因子

| 比較 | 週間時間 |
|---|---|
| サイクリスト（elite） | 25–30h |
| ランナー（elite） | 12–15h |
| トライアスリート | 35h（3スポーツ分散） |

- VO2max より**筋肉・腱・結合組織**がボトルネック
- 1歩 = 体重の2–4倍 × 数千〜数万回/週

### 1.8 Golden Zone 実践意味

| レベル | 意味 |
|---|---|
| 経験者 | **同日2質セッション** = ダブルスレッショルド |
| 典型日（elite） | AM: 6–8×3–5min / PM: 30×1min — 計50–70min質 |
| 初心者 | 週を通じた安定進歩、怪我サイクル回避 |
| エリート | 質ボリュームの倍増可能 |

**原則: The center holds. Everything else orbits around it.**

### 第1章 Summary

| # | 要点 |
|---|---|
| 1 | NOT HARDER, BUT RIGHT — ハードデーのコストが高すぎる |
| 2 | 閾値ペース = 約1時間持続可能 |
| 3 | Golden Zone = 閾値直下、HR 80–87%、短いフレーズ |
| 4 | 5メカニズム同時刺激 |
| 5 | 筋肉系が真のリミッター |
| 6 | 鍵は1ワークアウトではなく**このゾーンでのvolume蓄積** |

## 第2章：閾値の見つけ方

### 2.1 初めての乳酸曲線（14歳）

| ステージ | 乳酸 |
|---|---|
| 1 | 1.8 mmol/L |
| 2 | 2.3 |
| 3 | 3.4 |
| 4+ | 4.5 → 5.9 → 7.3 |

→ 「hard」が**数値・曲線上の点**になった

### 2.2 レベル別推奨開始法

| レベル | 開始法 | クロスチェック | マージン |
|---|---|---|---|
| レクリエ（週4–6h） | VDOT + 30分HRテスト | トークテスト、RPE、胸ストラップ | 余裕を大きく |
| 意欲的 | 3点法 or 乳酸プロファイル | フィールド+拡張トーク+HR | 低い結果を採用 |
| エリート/sub-elite | **乳酸測定** | — | — |

**最重要**: 精度が低いほど**マージンを大きく**。閾値**上**ではなく**下**で走る。

### 2.3 トークテスト

#### シンプル版 Protocol

| 会話 | 推定位置 |
|---|---|
| 1息で完全な文 | 閾値以下 |
| 数語 + 短いフレーズ | 閾値付近 |
| 単語のみ | 閾値 well above |

**Tip**: 毎回同じ固定ストーリー/歌詞

#### 拡張版（Foster協力 2022/2025）

| 段階 | Protocol |
|---|---|
| 準備 | 30–100語の固定テキストを暗記 |
| WU | 15分ジョグ |
| 本体 | 5–8×3分、ペース漸増、間1分ジョグ |
| 判定 | 各3分の**最後30–40秒**でテキスト朗読 |

| 回答 | 意味 |
|---|---|
| Yes | 容易 |
| Yes, but... | 努力必要 — **VT1付近** |
| No | 不可 — **VT2/RCT付近** |

Golden Zone = VT1 と VT2下の間

### 2.4 フィールドテスト

#### 30分タイムトrial（McGehee et al. 2005）

| Step | 内容 |
|---|---|
| 1 | 30分ベスト steady pace |
| 2 | 最初10分でリズム確立 |
| 3 | **最後20分の平均HR** = 推定閾値HR |
| 4 | Golden Zone = その値から **4–7 bpm 引く** |

#### VDOT テーブル（Daniels）

5K 20:00（4:00/km）ランナーの例:

| インターバル長 | ペース (min/km) | ペース (min/mile) |
|---|---|---|
| 短（1–3min） | 4:18–4:25/km | 6:56–7:07/mile |
| 中（4–5min） | 4:25–4:32/km | 7:07–7:18/mile |
| 長（8–12min） | 4:32–4:39/km | 7:18–7:28/mile |

**Golden Zone**: 標準T-paceより **+8–12秒/km** 遅く

### 2.5 最大心拍 — Hill Protocol

| Step | 内容 |
|---|---|
| 1 | 2–3分登る均等な坂 |
| 2 | WU 15–20分 |
| 3 | 1本目: コントロール hard（all-out ではない） |
| 4 | 2本目: hard + 最後30秒 max |
| 5 | 3本目: 最初から max |
| 6 | 間3–4分 |
| 7 | 最高HR ≈ true max |

#### 閾値HR計算

| レベル | 最大HRに対する% |
|---|---|
| 初心者 | 77–84% |
| Well-trained | **80–87%** |
| エリート | 82–89% |

例: max 195 → 閾値帯 156–170 bpm

### 2.6 HR変動（重要）

| 条件 | 閾値HR |
|---|---|
| 疲労時 | 低い |
| ピーク form | 高い（例: 13:06前 — 181/192 max） |
| 朝 | 5–7 bpm 低い |
| 23°C で 6×6min | 1本目→最後で7–10 bpm drift |
| 筋トーン高 | HR低 |

→ トークテストが**補正**として有効

### 2.7 3点法（Triangulation）

| Step | 内容 |
|---|---|
| 1 | 1–2週間で3検証テスト |
| 2 | 推奨: フィールド + 拡張トーク + HR法 |
| 3 | 不一致を確認 |
| 4 | 3つが **3–5 bpm または 5–7 sec/km** 以内 → 閾値発見 |

### 2.8 乳酸プロファイリング Protocol

| Step | 内容 |
|---|---|
| 1 | 5分インターバル、速度漸増 |
| 2 | 間30秒 pause |
| 3 | 各段階後に乳酸測定 |
| 4 | 曲線プロット |
| 5 | ゾーン調整 |

**条件統一**: トレッドミル/同一コース、同一WU、閾値上セッションは4日以上前

**個人プロトコル**: トレッドミルテスト → 2日easy → 軽TH → 2日easy → 屋外コントロール

### 2.9 保守的アプローチ

> When in doubt, slow down.

- 漸進的構造、終盤にvolume追加
- 終わって「もっとできた」と感じる方が良い

### 2.10 よくある間違い

| 間違い | 対策 |
|---|---|
| 1手法を盲信 | 最低2手法でクロスチェック |
| 古いレース結果 | 最近のパフォーマンスのみ |
| 日々の変動無視 | 近似値として扱い、安全側 |
| ウォッチ任せ | HR 3–5% マージン |
| 主観無視 | 感じが hard なら probably is |

### 第2章 Summary

| # | 要点 |
|---|---|
| 1 | 複数手法使用、精度低いほどマージン大 |
| 2 | 乳酸 = gold standard |
| 3 | トークテスト = 有用なクロスチェック |
| 4 | 30分TT + VDOT |
| 5 | 220-age 忘れ、Hill Protocol |
| 6 | HR はシフトする |
| 7 | 3点法 |
| 8 | 疑わしきは遅く |

## 第3章：負荷と6つの基礎柱

### 3.1 1990年代の問題

- アフリカ選手の支配 — 西洋の伝統的方法では volume 不足
- Peter Coe, Sam Bell でも不十分 → **10年の実験**

### 3.2 ノルウェーメソッド vs 伝統

| 伝統 | ノルウェーメソッド |
|---|---|
| 固定セッション、統一原理なし | **1つの固定中心**に全構造が回る |
| — | 最大volume の精密な有酸素、**筋肉系で制限** |

### 3.3 6つの柱

```
        [6] Interval Training
              |
    [2] Load — [CENTER: Golden Zone TH] — [5] Durability
              |
    [3] Muscular System — [4] Accuracy over Variety
              |
         [1] Specificity
```

### 柱1: Specificity（特異性）

| 種類 | 内容 |
|---|---|
| **機械的/外部** | レースペース、リズム、歩幅、路面 |
| **生理的/内部** | エネルギー供給、乳酸平衡、代謝安定性 |

**核心**: 1500/5K/10K で最も特異的なのはレースペース練習ではなく、**レースペースを持続可能にする内部capacity**

- レースペース = 高機械的ストレス、低volume
- 閾値ワーク = 大volume、低筋肉コスト

### 柱2: Load（3つの負荷）

| 種類 | 定義 |
|---|---|
| **General load** | Golden Zone の反復可能な週間コア |
| **Specific load** | TH → レースペースへの転移 |
| **Optimized load** | 中心を乱さない小さな追加（drip load） |

#### General Load

- エリート: 週2–3 DLTH で十分に近い
- 以下: 時間次第

#### Variation within Golden Zone

| 変化軸 | 例 |
|---|---|
| インターバル長 | 短/中/長を週で交替 |
| 強度 | マラソン〜15K pace |
| 休息 | 特に短intervalで重要 |
| 路面 | トラック/アスファルト/グラベル/トレッドミル |

#### Specific Load — なぜ Hill Training

- 筋力 + 神経支配（innervation）同時
- 速度抑制 → 怪我リスク↓
- 典型冬週: 土曜後2休息日 → 火曜THに最適

#### Optimized Load — 3オプション

| Option | 内容 |
|---|---|
| 1 | 未発達要素の強化（スピード等 — リスク大） |
| 2 | **Drip load** — 最小有効量の追加 |
| 3 | **X-session** — 週1、境界付きで強みを伸ばす |

### 柱3: Muscular System

- **24時間以内**: トーン↑・弾性↓（loading後）→ DLTH blocking の根拠
- ハード日間: トーン↓のため**完全保護**

#### 70%ルール

| ルール | 詳細 |
|---|---|
| イージー全日 | **HR < 70% max** — 例外なし |
| 13:06前の例 | イージー 4:10–4:20/km（max下70%） |
| レクリエ | 5:00–6:30/km も正しい |

```
<70% = Easy zone（正しい）
70-80% = Grey zone（悪いトレードオフ）
```

### 柱4: Accuracy over Variety

- Canova/Coe 型の多様性 vs **極端な精度**
- Golden Zone volume ceiling = 高いが**脆弱**
- **Precision drives progress, not variety**

### 柱5: Durability

| TH session後 | Max interval session後 |
|---|---|
| 回復予測可能 | 2日〜1週間（予測困難） |
| 連続性 | 中断サイクル |

- レクリエーションこそ連続性が重要（再開時怪我リスク高）

### 柱6: Interval Training

#### Micro-recovery

- 連続30分 TH → トーン漸増
- 30–90秒 rest → トーン部分正常化、pH改善

#### Speed Advantage

| 形式 | ペース例（TH 4:10/km） |
|---|---|
| 連続30分 | 4:10/km |
| インターバル | **3:50–4:00/km**（同 effort） |

差: **5–15 sec/km**

#### インターバル長ガイド

| 長さ | 役割 |
|---|---|
| 4–10分 | **Workhorse** — 6×6min, 4×10min |
| 1–3分 | 高品質維持、速いペース |
| 11–20分 | 安定ペース、月1–2回 |
| 20–45秒 | → 第8章 45/15 |
| Mixed | 3×10min + 10×45/15 等 |

**Tip**: 最初のrep 5–7 sec/km 遅く、漸増

### 第3章 Summary

| # | 要点 |
|---|---|
| 1 | ONE FIXED CENTER |
| 2 | SPECIFICITY: INTERNAL > EXTERNAL |
| 3 | LOAD: General / Specific / Optimized |
| 4 | 筋肉系が週を支配、easy < 70% |
| 5 | ACCURACY > VARIETY |
| 6 | DURABILITY = 予測可能回復 |
| 7 | INTERVALS > 連続 |

## 第4章：筋肉系 — 真のボトルネック

### 4.1 16歳のレース前夜

- 脚に重量感なし — springiness
- 初めて**筋肉そのもの**がパフォーマンスを決めた感覚
- → muscle tone 概念へ

### 4.2 真のボトルネック

| システム | 回復速度 |
|---|---|
| 心・肺 | 数時間 |
| 筋肉・腱 | **はるかに長い** |

### 4.3 Muscle Tone

| 概念 | 定義 |
|---|---|
| Resting tone | 完全弛緩時のベースライン張力 |
| Hard session後 | トーン↑ —  harder = longer to settle |
| Reference point | 多くのランナーは**正常化された筋肉を知らない** |

### 4.4 Elasticity & Heavy Legs

| 用語 | 意味 |
|---|---|
| Tone | ベースライン張力 |
| Elasticity | 伸長後の原長復帰能力 |
| Stiffness | 負荷下の変形抵抗 |

**Heavy legs** = 想像ではなく real change

### 4.5 休息が効かない理由

| 状態 | 結果 |
|---|---|
| 完全休息3日 | 最初のセッション**より重い** |
| Active recovery 60min easy | トーン正常化に有効 |
| 「Easy」が速すぎ | 休息でも正常化でもない — **最大の罠** |

### 4.6 Inflection Point

```
Easy → Golden Zone → Above threshold
                ↑
         Inflection point
         90% TH: 予測可能
         数sec/km above: トーン急上昇、回復2倍
```

### 4.7 TH vs Above — 予測可能性

| | TH session | Max interval |
|---|---|---|
| 筋肉への imprint | ほぼ同じ | 大きく変動 |
| 翌日予測 | 可能 | 2日〜1週間 |
| DLTH | 数時間後に再質可能 | — |

### 第4章 Summary

| # | 要点 |
|---|---|
| 1 | 心・肺は数時間、筋肉ははるかに長い |
| 2 | Muscle tone — hard後に上昇 |
| 3 | Reference point — 多くは未経験 |
| 4 | 休息 ≠ 正常化、active easy が必要 |
